# SEO: как вывести справку в выдачу

Краткие рекомендации, чтобы страницы справки (wiki) хорошо индексировались и попадали в выдачу по запросам вроде «как в телеге сделать то-то» (для нашей платформы — «как создать чат», «как пригласить по ссылке» и т.д.) и обгоняли конкурентов (статьи про Telegram, WhatsApp и др.).

---

## Что уже сделано в контенте

1. **Отдельная страница под каждый крупный раздел** (чаты, реферальная программа, безопасность, каналы, боты) — один URL под одну тему, меньше конкуренции ключевых слов внутри страницы.
2. **Заголовки в формате запроса пользователя** (H1/H2): «Как создать чат», «Как пригласить в чат по ссылке», «Как отправить голосовое сообщение», «Реферальная ссылка: как получить» и т.д. Так поисковики лучше сопоставляют страницу с запросом.
3. **Первый абзац = прямой ответ** на главный вопрос страницы (удобно для сниппета в выдаче).
4. **Блоки FAQ** в конце страниц — формат «вопрос — краткий ответ» хорошо подходит для расширенных сниппетов (FAQ schema).
5. **Внутренние ссылки** между разделами и на главную справку — укрепляют тематику и распределяют вес.
6. **YAML frontmatter** у каждой страницы: `title` и `description` — для подстановки в `<title>` и `<meta name="description">` при сборке сайта.

---

## Что сделать при публикации (техническая часть)

### 1. Сборка HTML из Markdown

Опубликуйте справку как сайт (а не только как сырые .md в репозитории). Варианты:

- **MkDocs** + mkdocs-material (поддерживает frontmatter через плагины).
- **Docusaurus** (React).
- **VitePress** (Vue).
- **Обычный статический сайт**: Markdown → HTML, в шаблон подставлять `title` и `description` из frontmatter.

Для каждой страницы в HTML должны быть:

- Уникальный `<title>` из frontmatter (до 60 символов, с ключевым запросом).
- `<meta name="description" content="...">` из frontmatter (до 155–160 символов, призыв кликнуть + ключевые слова).

### 2. URL и структура

- **Человекопонятные URL** без лишних параметров, например:  
  `/wiki/`, `/wiki/chats`, `/wiki/referral`, `/wiki/security`, `/wiki/channels`, `/wiki/bots`.
- **Один канонический URL** на страницу (canonical), без дублей с `?ref=` и т.п., если контент тот же.

### 3. Навигация и ссылки

- На каждой странице — ссылки «Назад к справке» и при необходимости на смежные разделы (уже есть в конце страниц).
- На главной справке — таблица/список со ссылками на все разделы (уже есть в [index.md](index.md)).

### 4. Скорость и мобильная версия

- Отдавать страницы быстро (CDN, сжатие, кэш).
- Верстка без горизонтального скролла на телефоне; читаемый шрифт — это повышает шанс на хороший mobile-индекс.

### 5. Схема для расширенных сниппетов (по желанию)

- **FAQPage** (JSON-LD) для блоков «Частые вопросы» на страницах — может дать расширенный сниппет в Google.
- **HowTo** для пошаговых инструкций (например, «Как создать чат») — подходит для пошагового сниппета.

Генераторы документации (MkDocs, Docusaurus, VitePress) часто имеют плагины для JSON-LD; можно добавить вывод FAQ и HowTo из тех же заголовков и списков, что уже есть в markdown.

## Ключевые запросы (на что ориентированы страницы)

| Страница | Примеры запросов |
|----------|-------------------|
| index | справка платформа чатов, как пользоваться мессенджером |
| chats | как создать чат, как создать группу, как пригласить по ссылке, голосовое сообщение, отложенное сообщение, отключить уведомления в чате, сколько человек в чате |
| referral | реферальная ссылка как получить, звёзды за приглашение, реферальная программа |
| security | безопасность чатов, вход без пароля, кто видит чаты |
| channels | каналы как в телеграм, есть ли каналы |
| bots | боты в чате, как добавить бота в чат |

Конкуренты — страницы вроде «как в телеграм создать группу», «как пригласить по ссылке в телеграм». Наша ниша — та же тематика (создать чат, пригласить, голосовое, отложенное и т.д.), но для **нашей платформы**; в тексте явно указываем название платформы и контекст («в платформе приватных чатов»), чтобы не было путаницы с Telegram/WhatsApp и чтобы ранжировались запросы с уточнением платформы или «как в мессенджере сделать X».

## Дальнейшие улучшения

- Добавить **отдельные короткие страницы** под самые частые запросы (например, «Как отправить голосовое сообщение» — одна страница), если по анализу поиска они сильно востребованы.
- Регулярно **обновлять дату** и текст «актуально на …» внизу страниц.
- Следить за **Core Web Vitals** и удобством чтения на мобильных.
- При появлении каналов/ботов — **дополнить разделы** и добавить запросы «как создать канал», «как добавить бота в чат» с пошаговыми инструкциями.
