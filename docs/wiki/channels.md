# Каналы: есть ли в платформе (как в Telegram)

Краткий ответ на запросы вроде **«как создать канал»**, **«есть ли каналы как в телеграм»**, **«каналы в мессенджере»** в контексте платформы приватных чатов.

---

## Есть ли каналы в платформе?

**Нет. Каналы в платформе пока не реализованы.**

Сейчас есть только **чаты** (группы с владельцем и участниками, вход по пригласительной ссылке). Функции **каналов** (публичные или приватные каналы с подписчиками, где посты публикует автор/админ, а подписчики только читают и иногда комментируют) в текущей версии **нет**.

---

## Чем каналы отличаются от чатов (для справки)

| | Чат (группа) | Канал (как в Telegram) |
|--|--------------|-------------------------|
| Кто пишет | Все участники | В основном владелец/админы |
| Вход | По пригласительной ссылке | По ссылке или поиск (если публичный) |
| В платформе | ✅ Есть | ❌ Пока нет |

Когда каналы появятся, описание будет добавлено в эту справку и в приложение.

---

## Что есть вместо каналов сейчас

- **Чаты** — для общения группы по приглашению: создание чата, приглашение по ссылке, текст, голосовые, файлы, видео, отложенные сообщения. Подробнее: [Чаты: как создать и пользоваться](chats.md).
