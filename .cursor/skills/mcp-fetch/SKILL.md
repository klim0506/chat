# Fetch MCP

Получение содержимого веб-страницы по URL в виде markdown. Требуется настроенный Fetch MCP server (uvx, pip или Docker).

## Инструмент

**fetch** — один основной инструмент.

| Параметр | Тип | Описание |
|----------|-----|----------|
| `url` | string, обязательно | URL страницы |
| `max_length` | integer | Макс. символов в ответе (по умолчанию 5000) |
| `start_index` | integer | Индекс символа, с которого начать (по умолчанию 0) |
| `raw` | boolean | true — вернуть сырой HTML; false — markdown (по умолчанию) |

## Рекомендации

1. **Длинные страницы**: если ответ обрезан, вызвать fetch с тем же `url` и `start_index`, равным индексу после последнего полученного фрагмента (постраничное чтение).
2. **Предпочитать markdown**: не указывать `raw: true`, если не нужен именно HTML — markdown удобнее для анализа и цитирования.
3. **Ограничение длины**: при необходимости увеличить `max_length` в разумных пределах, чтобы уложиться в контекст.
4. **Безопасность**: Fetch может обращаться к локальным/внутренним адресам; не передавать чувствительные URL в незащищённом окружении.

## Когда применять

- Пользователь дал ссылку и просит разобрать содержимое
- Нужна актуальная документация или статья с сайта
- Требуется сравнить или процитировать контент страницы
